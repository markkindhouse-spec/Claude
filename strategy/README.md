# Strategy Log

Running record of Mark Kindhouse's strategic thinking on the BDX heavy
civil platform build (3-5 year horizon), AI/equipment automation adoption,
and the 6-12 month technology lookahead.

Most of the actual thinking happens out loud — in the Claude mobile app's
voice mode, in person, or in this Claude Code session via the `/bdx-spar`
skill. This log exists because none of those conversations persist into
each other on their own. After a session, drop in what was decided, what's
still open, and what changed from last time.

## How to add an entry

New file per session: `strategy/sessions/YYYY-MM-DD.md`, copied from
`strategy/sessions/TEMPLATE.md`. Doesn't need to be exhaustive — a decision,
a rejected option, and an open question is worth more than a full
transcript.

## Files

- `open-questions.md` — the current live list of unresolved questions
  across all three threads (platform strategy, automation, tech
  lookahead). Update this as questions get answered or new ones surface;
  it's meant to always reflect the current state, not a history.
- `sessions/` — dated entries, one per sparring session, oldest to newest.
